# Changelog

All notable changes to `aldytoi/laravel-toi` will be documented in this file.

## [1.0.0] - 2026-08-27

### Added

- Laravel 12 support
- `toi:install` Artisan command
- Service provider with auto-discovery
- User model with password hashing cast
- Users migration
- Base Controller
- Authentication controllers (Login, Register, Logout)
- Web routes with authentication middleware
- Login page with Tailwind CSS and Lucide Icons
- Register page with Tailwind CSS and Lucide Icons
- Admin dashboard with sidebar, navigation, statistics, and activity
- Responsive design (mobile, tablet, desktop)
- `@lucide` Blade directive for inline SVG icons
- Configuration file (`toi.php`)
- File conflict protection (skip existing files)
- `--force` flag to overwrite existing files
- Idempotent installer
- CSRF protection on all forms
- Session regeneration on login
- Accessible UI (semantic HTML, labels, aria-labels, focus states)
- PHPUnit test suite
- README documentation
- CHANGELOG
